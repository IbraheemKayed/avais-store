# 🛍️ Avais Store

> A fully-featured e-commerce Flutter application for clothing and fashion.

---

## 📱 Overview

Avais Store is a cross-platform mobile shopping app built with Flutter, offering a smooth and modern shopping experience. Users can browse products, manage their cart, and complete purchases seamlessly.

---

## ✨ Features

- 🛒 Product browsing with categories and filters
- ❤️ Wishlist and favorites management
- 🛍️ Shopping cart with quantity control
- 👤 User authentication (Login / Register)
- 📦 Order management and tracking
- 🔍 Product search functionality
- 📱 Fully responsive UI for all screen sizes

---

## 🛠️ Tech Stack

| Technology | Usage |
|---|---|
| Flutter | Cross-platform UI framework |
| Dart | Programming language |
| Firebase Auth | User authentication |
| Firebase Firestore | Database |
| REST APIs | Product & order data |
| Provider | State management |

## 🚀 Getting Started

### Prerequisites
- Flutter SDK >= 3.0.0
- Dart >= 3.0.0
- Android Studio or VS Code

### Installation

```bash
# Clone the repository
git clone https://github.com/IbraheemKayed/avais-store.git

# Navigate to project directory
cd avais-store

# Install dependencies
flutter pub get

# Run the app
flutter run
```
